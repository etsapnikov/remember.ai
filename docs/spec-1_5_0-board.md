# Запомин.ai 1.5.0 — «Неделя» доской. Спецификация для разработки

Основание: `tz-design-1_5_0.md` (Д-51…Д-55), система 1.3 (`Controls.kt`, палитра, лестница 4/8).
Макеты: `Запомин.ai - Неделя доской 1.5.0.dc.html` (открывать в браузере, рядом `support.js`).
Экраны в макете: П1–П6 портрет, Л1–Л2 ландшафт.

Модель данных не меняется. Новое в коде: пейджер колонок, стопка «Входящие», свайп карточки,
drag в ландшафте, перенос итога недели в «Дни», переименование таба.

## 2. Заголовки колонок (пейджер)

- Контейнер 52 dp, поля 20, gap 20, нижний разделитель `rgba(38,32,27,.09)`.
- Активная: Manrope 20 ExtraBold `#26201B`, нижняя линия 2 dp акцентом `#B4462A`, счётчик моно 13 акцентом.
- Неактивные: Manrope 16 SemiBold `#8A7B6D`, счётчик моно 13 того же цвета.
- Тап по заголовку — переход к колонке (анимация горизонтального сдвига 200 мс).
- Свайп по пустому месту доски листает колонки. Свайп по карточке — перенос (§5), не листание.
- Ландшафт: заголовок каждой колонки внутри колонки — 17 Bold, активной колонки нет (все видны),
  но «Сегодня» держит акцентную линию 2 dp как «текущую»; остальные — разделитель 1 dp.

## 3. Стопка «Входящие»

Источник: живые дела с `dueAt == null && window == null && exactAt == null`, не повторы.
Сортировка — по `createdAt` возрастанием (старые сверху).

Вёрстка (П1):
- Контейнер: фон `#F6EEE3`, паддинг 16/20/18, нижний разделитель.
- Шапка: слева `ВХОДЯЩИЕ · 45` (моно 12, трекинг 0.1em, капс, `#8A7B6D`), справа подсказка
  `свайп — в день` (моно 12).
- Голос продукта — один раз, Literata Italic 15/1.45 `#6E6055`:
  «Ты не сказал, когда — значит, дня нет. Дай его здесь, и я вернусь.»
  Показывается до первого успешного переноса из стопки, потом скрывается навсегда (флаг в prefs).
- Карточки: показываем 3 верхние, gap 8. Ниже — `ещё N` (моно 13). Тап по «ещё N» раскрывает
  стопку целиком в том же блоке (доска уезжает вниз); повторный тап или скролл вверх — сворачивает.
- При N ≤ 3 строка «ещё» не рендерится. При N = 0 весь блок не рендерится, доска начинается сразу
  под заголовками колонок (П5).
- Ландшафт: стопка 228 dp слева, карточки 15/1.35, показывается столько, сколько влезает по высоте,
  затем `ещё N`.

## 5. Жесты переноса (Д-53)

### 5.1 Свайп по карточке (портрет и ландшафт)
- Порог срабатывания — 96 dp или скорость > 800 dp/с. До порога — карточка следует за пальцем
  с резистентностью 0.6 после 64 dp.
- Направление: вправо — на колонку позже (Входящие → Сегодня? **нет**: Входящие → Завтра;
  Сегодня → Завтра; Завтра → Позже). Влево — на колонку раньше (Позже → Завтра; Завтра → Сегодня;
  Сегодня → влево = «Входящие», то есть снять срок). Из «Позже» вправо — резиновый откат.
- Из стопки «Входящие» вправо назначает **завтра утром** (`window = MORNING`, день +1). Логика:
  человек раскладывает стопку на будущее, «сегодня» — осознанное решение через тап.
- Подложка под карточкой: `rgba(180,70,42,.12)`, радиус 18. На вскрывшейся стороне — метка
  моно 13 акцентом в две строки: название колонки и стрелка (`ЗАВТРА` / `→`). Карточка сохраняет
  ширину (321 dp), сдвигается только трансформом (П2).
- После порога карточка уезжает за край за 180 мс, стопка/колонка схлопывается за 200 мс.
  Приземление в невидимую колонку не анимируем.
- Снизу появляется строка отмены на 4 с: 56 dp, фон `#26201B`, радиус 18, поля 16, слева текст
  «Завтра утром» (15 SemiBold `#FAF4EC`), справа кнопка «Вернуть» (44 dp, `#E08863`).
  Строка сдвигает доску вверх, не перекрывает контент. Новое действие заменяет строку.

Вызовы: `repository.editItem(id, window=…)` / `editItem(id, exactAt=…)`; снятие срока —
`editItem(id, window=null, exactAt=null, dueAt=null)`.

### 5.2 Тап по карточке → шторка
Существующий `EditItemSheet` (П3), заголовок блока `ДЕЛО` вместо `ТЕКСТ`, под текстом моно
`Раздел · дата · без срока` (или текущий срок). Блок «Когда вернуть» без изменений; чип текущего
срока предвыбран. Ряд действий «сделано / не надо / Поправить» — под чипами, затем
«Сохранить» 56 + «Отмена». «Поправить» разворачивает шторку в полную правку пункта.

### 5.3 Drag & drop — только ландшафт
- Long-press 300 мс поднимает карточку: тень `0 18px 32px -12px rgba(38,32,27,.5)`, поворот −2°,
  масштаб 1.0. На исходном месте — пунктирный плейсхолдер `1px dashed rgba(38,32,27,.25)` с моно
  «карточка в руке».
- Колонка под пальцем: фон `rgba(180,70,42,.08)`, внутренняя обводка 2 dp `rgba(180,70,42,.45)`,
  радиус 18, заголовок становится 800/акцентная линия; место приземления — пунктир 2 dp
  `rgba(180,70,42,.4)`, 56 dp (Л2). Остальные карточки — `alpha .5`.
- В шапке справа моно 12 «отпусти — назначу день».
- Отпускание в «Сегодня» — `window` по текущему времени суток (ближайшее окно); «Завтра» — утро +1;
  «Позже» — открывает шторку с чипом «выбрать день». Отпускание вне колонок — откат 200 мс.
- В портрете long-press не делает ничего, кроме haptic; drag не запускается.

## 6. Пустые состояния (Д-54)

## 7. «Дни»: итог недели сверху (Д-55)

Над кнопкой «Рассказать про день» — карточка `SurfaceCard` радиус 24, паддинг 20, gap 14 (П6):
- `ИТОГ НЕДЕЛИ` моно 12 капс, предупреждающий `#A9781A`;
- заголовок 26 ExtraBold тем же цветом (цвет заголовка — по типу итога, как в 1.4);
- текст 16/1.5 `#4A3F36`;
- разделитель, две пары «подпись моно 13 — значение 15 Bold»:
  `самое старое живое дело — 20 дней`, `разложено из входящих — 6` (новая метрика: число переносов
  из стопки за 7 дней).
Блок «Наблюдения» удаляется вместе с его данными в UI (модель не трогаем).
Карточка не рендерится, если итога за неделю нет.

## 10. Приёмка

- [ ] На данных 8 сентября (1 · 0 · 1, стопка 45) экран открывается стопкой и доской, пять дел
      раскладываются за минуту свайпами.
- [ ] Ни один текст дела не обрезан в обеих раскладках.
- [ ] Свайп вправо из стопки ставит завтра утром; строка отмены возвращает дело в стопку.
- [ ] Повтор не переносится свайпом и drag; в шторке только «не повторять».
- [ ] При 0 в колонке — строка моно, при 0 сделано — ничего.
- [ ] Ландшафт: три колонки + стопка без горизонтального скролла; drag подсвечивает колонку.
- [ ] Портрет: long-press не запускает drag.
- [ ] Итог недели в «Дни» сверху; «Наблюдения» и старый экран «Неделя» не доступны.
- [ ] Ни одной цели меньше 44 dp; карточка не ниже 56.
- [ ] Все тексты — как в макетах, посимвольно.
