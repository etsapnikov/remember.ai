# Архив

Здесь лежат закрытые ТЗ, планы и бэклоги — до версии 1.0.1 включительно.

**Работать по ним больше нельзя.** С 16 августа 2026 новый объём приходит только
отдельным ТЗ на конкретную версию; старые списки задач закрыты как класс, даже
там, где в них остались невыполненные пункты.

Причина простая: бэклог, который живёт дольше пары версий, перестаёт отражать
продукт. Часть его уже сделана иначе, часть отменена решением по ходу, а часть
держится только тем, что однажды была записана. Отличить одно от другого через
месяц нельзя, и такой список начинает управлять работой вместо владельца.

Что из незакрытого имеет значение — перенесено в `docs/state-1.0.1.md`, раздел
«Открытые вопросы», и уже не как задачи, а как факты о состоянии. Задачами они
станут снова, только если попадут в новое ТЗ.

Читать эти файлы стоит ровно за одним: понять, почему что-то сделано именно так.
